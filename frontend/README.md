Digital Warranty Tracker (Group Project)

Digital Warranty Tracker is a full-stack web application designed to help users efficiently manage and track their product warranties in one place. The goal of this project is to prevent the loss of important warranty details and provide an easy way to monitor expiry dates and maintenance records.

🚀 Features
User authentication (Signup/Login)
Add, update, and delete products
Track warranty expiry dates
Store maintenance/service records
Dashboard to view and manage all products
🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript (React)
Backend: Node.js, Express.js
Database: MongoDB
Tools: Git, GitHub, Postman

⚙️ How to Run Locally

1. Clone the Repository
   git clone https://github.com/your-username/Digital-Warranty.git
   cd Digital-Warranty
2. Setup Backend
   cd backend
   npm install

Create a .env file and add:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key

Run backend:

node server.js 3. Setup Frontend
cd frontend
npm install
npm start
⚡ How It Works
Users register and log in securely
After login, they can add product details (purchase date, warranty period, etc.)
The system stores all data in a database
Users can view warranty status and maintenance history through a dashboard
